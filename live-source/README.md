# Reviewed live source snapshot

This folder mirrors selected voice/controller/bridge source from the authorized Windows live directory. MANIFEST.json records live SHA-256 hashes and exported Git blob hashes. The web dashboard and original generated office asset accompany the native UI source.

This is a reviewed subset, not a standalone installer. Host dependencies, licensed datasets, the original application modules, default configuration and local model setup remain required. Credentials, account configuration, runtime logs, user memory, databases and generated speech are excluded.

Source synchronization does not prove service authentication, funded voice quota, live microphone accuracy or successful completion by all agents. Consult the audit runbook and actual diagnostic results.
